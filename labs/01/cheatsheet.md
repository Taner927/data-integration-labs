### Text

**Markdown** · Formats documents, web pages, code documentation and notes using simple symbols like hashtags and asterisks instead of complex HTML tags.

```markdown
**bold** and *italic*
```

**bold** and *italic*


### Lists

**Markdown** · Creates lists for structured listing.

```markdown
- first item
- second item
```

- first item
- second item


### Links-and-images

**Markdown** · Points to links and images on other or the same website. Images can also be added to the repository.

```markdown
[Link text](https://example.com)
[Alt text](image.png)
```

[Link text](https://example.com)


### Code

**Markdown** · Has its own syntax for writing code, which is then displayed as formatted code.

```markdown
`inline code`
```

`inline code`


### Quotes

**Markdown** · Connects your text to outside resources or highlights cited text.

```markdown

```

### Tables

**Markdown** · Organizes and presents data in a structured, grid-like format of rows and columns directly within plain text.

```markdown

```
